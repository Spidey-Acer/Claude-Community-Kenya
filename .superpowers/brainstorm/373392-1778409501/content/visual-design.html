Accessibility — non-negotiable
Keyboard
  • Tab cycles chips → input
  • Esc = skip and dismiss
  • Enter sends free text
  • Focus trap inside modal until skip/complete
Screen readers
  • role="dialog" aria-modal="true"
  • Streaming text in aria-live="polite"
  • Each chip = <button> with explicit label
  • Skip link is the first focusable element
Motion
  • prefers-reduced-motion → no entry choreography, no streaming animation
  • Cursor blink disabled
Contrast
  • All text ≥ WCAG AA (4.5:1)
  • Chip focus ring: 2px green, 3px offset
  • Errors announced via aria-live="assertive"
