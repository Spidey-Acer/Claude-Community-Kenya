# Reports

Public PDF reports published by Claude Community Kenya. Files in this folder
are served statically at `https://claudekenya.org/reports/<filename>` via
Next.js's `public/` directory — no route or redirect required.

These are Claude Community Kenya documents: event recaps, session summaries,
and similar community records intended for public, stable-URL access.

## Current reports

- `claude-conversations-nairobi-2026-08-29.pdf` — Claude Conversations Nairobi
  (2026-08-29) event report.
